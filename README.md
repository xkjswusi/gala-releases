# GALA American Lunar Almanac · 大美阴历

A US-configured Chinese style lunar almanac that incorporates calendars, observances, and other data from cultures and traditions across time and space. Users are empowered to build custom configurations.

## Download

Android installation packages (APK) are distributed through the [Releases](../../releases) section.

The app is also available on Google Play.
